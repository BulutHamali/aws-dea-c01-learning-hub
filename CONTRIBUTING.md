# Contributing

Start with a focused issue or pull request. Include the affected guide, the change, and an official AWS source when the behavior depends on the service.

- Explain the requirement that drives the choice. Define acronyms and add a concrete example when a concept is easy to confuse.
- Verify service behavior against AWS documentation. Link to the relevant page and distinguish prerequisites from defaults.
- Write original scenarios and explain the alternatives. Keep recalled exam questions and copied commercial practice questions out of the repository.
- Use fictional records. Test every new relative link from the page where it appears and run any executable example.
