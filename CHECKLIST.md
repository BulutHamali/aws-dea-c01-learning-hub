## Milestones

- [ ] Take the [diagnostic](practice/diagnostic.md) and mark low-confidence answers.
- [ ] Domain 1: explain replay after an outage, safe API retries, and how to pick Glue, EMR, or Lambda.
- [ ] Domain 2: pick a storage class from a retrieval deadline, design DynamoDB keys from a query, and load Redshift so a rerun is safe.
- [ ] Domain 3: trace a missing partition end to end, read a Spark skew pattern, and write a window function from memory.
- [ ] Domain 4: fix a cross-account KMS denial, explain why Lake Formation filters need S3 access removed, and name the right audit evidence.
- [ ] Complete at least two [hands-on labs](labs/README.md#hands-on-labs), or all three [paper workshops](labs/README.md#paper-workshops).
- [ ] Score 75% or better on the [timed set](practice/timed-set.md), counting guesses as misses.
- [ ] Score 75% or better on the [full mock](practice/full-mock.md) under exam timing.
- [ ] Clear every weak skill with the [question bank](practice/question-bank.md).
- [ ] Take AWS's official practice exam for an independent readiness check.

The 75% target is a study heuristic, not an AWS figure. AWS reports a scaled score, so use practice percentages to find weak areas rather than to predict your result.
